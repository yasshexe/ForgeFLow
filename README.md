# ForgeFlow — Manufacturing App Demo

A Flutter UI prototype based on the handwritten machine production workflow.

## Included demo screens
- Production dashboard
- Active jobs
- Job detail / production workflow
- QR scan placeholder
- Alerts
- Photo/document quick actions

## Run
1. Install Flutter.
2. Create a Flutter project or replace the `lib/main.dart` and `pubspec.yaml` with these files.
3. Run:
   flutter pub get
   flutter run

This demo uses mock data only. Backend, authentication, real camera upload, QR scanning, PostgreSQL, and Django API integration come next.
